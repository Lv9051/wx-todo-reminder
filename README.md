# 强芯待办 v1.3.0

一个简洁的 Windows 待办软件。先记事，需要时再提醒自己，或通过微信私聊、群内 @ 提醒别人。无需 AI API，不消耗 AI token。

## 使用

完整解压安装包，双击 **强芯待办.exe**。支持 Windows 10/11 64 位，需要 Microsoft WebView2 Runtime（多数 Windows 电脑已有；缺少时可从 [Microsoft 官方下载页](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)安装）。无需安装 Python。

- 输入标题，按 Enter 保存普通待办。点击标题查看完整内容或编辑；需要时再开启提醒。
- “我的待办／我交办的／全部”切换查看范围。负责人可独立设置，微信收件人不一定是任务负责人。
- 首次提醒默认当前时间；可选择只提醒一次，或每 N 小时、天、周重复提醒。
- 私聊和群内 @ 支持多位对象，每行填写一人。同轮同会话的提醒合并发送，不包含内部任务编号。录入时遇到同对象、同分钟的已有提醒会显示提示，可查看原事项或继续单独保存；查看已有事项时保留新草稿。
- 完成进入历史，按完成日期分组，可按月筛选、搜索并逐段加载，记录长期保留；更多菜单中可暂停或删除。删除后取消未发提醒，可撤销或在历史的回收站恢复；回收站保留 30 天，到期清理前自动备份。升级已有回收站事项从升级日起重新保留 30 天，恢复备份也会延长其中删除项的保留期。有提醒的事项恢复后先暂停，避免立即发出过期提醒。
- 清单顶部更多菜单提供批量选择和全部提醒。批量工具栏只在选择时出现。
- 设置里可开启登录启动、桌面待办小窗、柔和提示音；圆角小窗保持固定大小，支持滚轮、拖动滚动条和完成事项，默认显示自己的待办，也可切换全部。

关闭主窗口后，调度仍在托盘继续运行；右键绿色对号图标可打开清单、暂停提醒或退出。退出程序、电脑休眠／关机时不能执行提醒。

## 微信提醒

微信必须已登录，电脑桌面需可操作。自动化会临时切换微信会话；到点直接尝试发送，不等待键鼠空闲。已有草稿时保留草稿，稍后重试；发送结果不明确时暂停该事项，请核对后恢复，避免重复发送。多个提醒按顺序执行，发送记录可查看结果和等待原因。“微信已执行发送”不代表对方已读。

目前在 Windows 微信 **4.1.13.65** 使用过私聊和群内真实 @；其他版本请先用自己允许的对象验证。请填写完整且唯一的联系人备注名、微信群名与成员名称，无需置顶。个人微信离线时不能靠本软件继续发消息。

## 数据与升级

清单自动保存在当前 Windows 用户的 `%LOCALAPPDATA%/WXTodoReminder/reminders.db`；品牌改名不改变数据目录。更换解压位置或升级不会重新创建空白清单。设置里可导出／恢复备份，恢复前自动备份当前数据。

升级前从托盘退出旧软件，保留原 `data` 文件夹。首次升级会复制旧清单并备份，固定用户目录已有清单时不会用旧数据覆盖。需导入其他旧清单时，使用设置中的恢复备份。原数据库不删除。

开启登录启动后，程序会复制到固定用户目录；正常启动新版会更新已开启的启动副本。若提示旧程序仍在运行，请从托盘退出后再启动。

需要便携运行时可使用 `强芯待办.exe --portable`；此时数据保存在程序旁的 `data`。手机版与云同步尚未提供。

## 隐私

待办数据保存在本机，只监听 127.0.0.1。分发包不含作者的数据库、联系人、聊天记录、凭据、日志或本地开发文档。不自动解析微信聊天，也不将待办上传到云端。

## 从源码运行或构建

Windows、Python 3.12：先运行 `setup.ps1` 安装依赖，再运行 `start.bat`。构建免安装包：

```powershell
python -m pip install -r requirements-build.txt
python scripts/build_release.py
```

开源协议为 Apache-2.0，第三方依赖许可见 `THIRD_PARTY_NOTICES.md` 与安装包 `LICENSES`。
